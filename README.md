# agentic_ai
Labs for the Agentic AI course by DeepLearning.ai (Andrew Ng)

## Repository URL

**Remote URL (HTTPS):** `https://github.com/zaffnet/agentic_ai.git`

**Remote URL (SSH):** `git@github.com:zaffnet/agentic_ai.git`

## Connect Your Local Repository

If you already have a local repository and want to push your code to this remote, follow these steps:

```bash
# Navigate to your local repository
cd /path/to/your/local/repo

# Add this repository as a remote named 'origin'
git remote add origin https://github.com/zaffnet/agentic_ai.git

# Verify the remote was added
git remote -v

# Push your code to the remote repository
git push -u origin main
```

If you prefer using SSH:

```bash
git remote add origin git@github.com:zaffnet/agentic_ai.git
git push -u origin main
```

### If 'origin' Already Exists

If you already have a remote named 'origin', you can either rename it or use a different name:

```bash
# Option 1: Rename existing remote
git remote rename origin old-origin
git remote add origin https://github.com/zaffnet/agentic_ai.git

# Option 2: Use a different name
git remote add agentic https://github.com/zaffnet/agentic_ai.git
git push -u agentic main
```
